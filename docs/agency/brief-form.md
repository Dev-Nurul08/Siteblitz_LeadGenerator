# Brief form (the same fields as the "Send a brief" form on https://siteblitz.vercel.app/agencies)

When a brief arrives by email instead of the form, copy it into these fields. A brief is complete only when every
field marked * is answered; reply to ask for what is missing (one message, all questions together).

| Field | Required | Values |
|---|---|---|
| Agency name | * | text |
| Your name | * | text |
| Email | * | text |
| WhatsApp / phone | optional | text (only for project communication the agency started; never for cold contact) |
| City and country | * | text |
| What to build | * | Landing page / Three-page site / Something else |
| Stack required | optional | Any / Next.js / WordPress / Shopify / Webflow / Other |
| Design ready | * | Approved design / Use an existing demo layout / Not yet |
| Content ready | * | Yes / Partly / Not yet |
| Deadline | optional | date |
| Development budget | optional | text |
| Links and notes | optional | text (design file, reference sites, client sector) |

## How to answer a brief (within one business day)
1. Stack is not Next.js/React and we have not built it before -> say so honestly, decline or ask for time to check.
2. Design "Not yet" -> design is not included; ask whether they will supply it or want an existing demo layout.
3. Content "Partly / Not yet" -> quote anyway, but the dates start only at ready-to-build.
4. More than 6 sections (landing) or 12 sections / 3 pages (site) -> quote add-ons or a custom scope.
5. Send the quote from `quote-template.md`. Status `AWAITING_DEPOSIT`.

## Questions to ask when the brief is thin (one message)
- Which page type, and how many sections?
- Is the design approved? Please share the file or the reference you want us to follow.
- Is the final copy ready, and the images?
- Where should the site be deployed (your hosting, the client's hosting, or a static build you upload)?
- Where should the form send enquiries?
- Who at your agency approves staging?
- What is the deadline?
